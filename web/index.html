简介

AppOpt 是一款 Android 应用 CPU 亲和性管理工具。基于规则配置文件，将指定应用的进程与线程绑定到合适的 CPU 核心（小核省电、大核高性能），配置保存后即时热加载，无需重启应用。

使用说明
  1. 规则页点击「添加」，输入应用包名，可同时配置包级默认（可选）与多条线程规则后一次保存
  2. 设置页可配置 cpuset 目录名与配置文件路径（仅 KPM 模式）
  3. 配置文件也可直接手工编辑，保存后自动热加载
  4. 更多规则编写说明参考官网文档
